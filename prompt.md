## 1. Project Overview

**Problem:** People return to long, unread chat conversations and miss what matters: deadlines, tasks assigned to them, decisions, and direct mentions. Existing AI summarizers usually upload private conversations to the cloud.

**Solution:** A simple micro-app where the user pastes or uploads a chat export and instantly sees what they missed, with everything processed locally on their device.

**Key features (MVP, planned):**
- Paste or upload a chat export (WhatsApp .txt) and enter "your name"
- Short summary of the missed conversation
- Highlighted mentions of the user, deadlines, decisions, and action items
- Priority ranking (High / Medium / Low) based on urgency and relevance
- Clear "100% local: nothing leaves this device" indicator

**Constraints:** Solo developer, 2 hours total, local-first (no conversation data leaves the device).

---

## 2. Tech Stack & Architecture

**Planned stack (not yet built):**
- UI: React + Tailwind (initial UI generation planned with v0)
- Code generation/editing: Antigravity (planned), Claude (planning and assistance)
- Hosting: Vercel, static site with no backend
- Storage: browser only, no database, no server

**Planned architecture (all in the browser):**

```
Chat text -> Parser -> Signal detector -> Priority scorer -> Summary builder -> Results UI
```

| Module | Responsibility |
|---|---|
| Parser | Convert WhatsApp-style text into {sender, time, text} messages |
| Signal detector | Rule-based detection of mentions, deadlines, questions/requests, decisions, action verbs |
| Priority scorer | Explainable point score mapped to High / Medium / Low |
| Summary builder | Template-based summary from counts and top-scored items |
| Results UI | Summary card plus sections for mentions, deadlines, decisions, action items |

**Design decision:** Rule-based processing first, because it is fast, fully local, and reliable within a 2-hour limit. A local in-browser model is a stretch goal only, if time remains.

## 4. Debugging

After the first analyzer run (Entry 5), v0 itself flagged three weaknesses in its own message:
1. "Final decision." was rated Low (only +2 for the decision word, below the Medium threshold of 3).
2. Any message ending in a question mark counted as an action item (for example "We agreed to go with the blue pricing page, right?").
3. 24-hour times such as "15:00" were not detected; only "3pm" style times were.

Causes 1 and 2 came from the scoring rules written in the Entry 5 prompt, not from a v0 bug. Fixed with the Entry 6 prompt. Known side effect reported by v0 after the fix: because "please" counts as a request phrase, a notice like "Launch moved to Oct 20 - please update your calendars" now appears under Decisions, Deadlines, and Action items. Not yet changed.

## 5. AI Features & Design

- **UI/UX (Entry 3):** Layout, "100% local" badge, input area, four result sections, and color-coded priority tags were generated by v0 from a single prompt. Real chat analysis is not implemented yet; the page currently returns mock results.
- **Analysis design (Entries 5-6):** No AI model is used in the app. Messages are scored with transparent keyword rules (name/@mention, deadline words and times, requests, decision words, recency) and mapped to High / Medium / Low, with all processing in the browser so chats never leave the device. A score display next to each priority tag was requested in Entry 6.

### Entry 5: Rule-based analyzer
- **Date:** 2026-10-09
- **AI tool/model:** v0 by Vercel
- **Prompt / instruction (exact):**
  ```
  Replace the mock analysis with a real rule-based analyzer in lib/analyze-chat.ts.
  Input: the parsed messages from parse-chat.ts and the user's name.
  For each message, add points:
  - +3 if it contains the user's name or @name (case-insensitive)
  - +3 if it contains a deadline word (today, tomorrow, tonight, EOD, ASAP, by + weekday, due, deadline, a time like 3pm, a date like Oct 20)
  - +2 if it is a question or request (ends with ?, or contains "can you", "could you", "please", "need you to")
  - +2 if it contains a decision word (decided, final decision, agreed, we go with, let's go with, finalized, approved)
  - +1 if it is in the last 25% of messages
  Priority: 5 or more = High, 3-4 = Medium, below 3 = Low.
  Put messages into the four sections: Mentions of you, Deadlines, Decisions, Action items (a message can appear in more than one).
  Build the summary card text from the counts and the top 2 scored messages using a template, no AI model.
  Keep everything in the browser. Remove the temporary debug view.
  ```
  (Prompt drafted with Claude's help, then run in v0 as written.)
- **Purpose:** Replace mock results with real, explainable, fully local analysis.
- **Files/components affected:** `lib/analyze-chat.ts`; v0 also moved the sample chat to `lib/sample-chat.ts` and added a `score` field to each result (not shown in the UI at that point).
